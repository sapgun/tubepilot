🎬 TubePilot 개인정보처리방침

1. 수집하는 정보

TubePilot은 스폰서 구간 정보를 조회하기 위해 시청 중인 YouTube 영상의 ID를 SponsorBlock API(sponsor.ajay.app)로 전송합니다. 이는 구간 데이터를 받아오는 용도로만 사용됩니다.

그 외의 개인정보(이름, 이메일, 계정 정보, 시청 기록 등)는 수집하지 않습니다.

2. 기기에만 저장되는 정보

다음 정보는 사용자의 브라우저 로컬 저장소(chrome.storage.local)에만 저장되며, 외부 서버로 전송되지 않습니다.

  • 확장 설정 (광고 스킵 여부, 카테고리 선택, 패널 위치·투명도 등)
  • 다시보기 라이브러리 (저장한 영상의 제목·태그·메모)

3. 제3자 제공

수집한 정보를 제3자에게 판매·제공하지 않습니다. 단, 위 1항의 SponsorBlock API 조회 시 영상 ID가 전송됩니다.

4. 데이터 삭제

확장을 삭제하면 로컬에 저장된 모든 데이터가 함께 삭제됩니다. 백업 파일(JSON)은 사용자가 직접 관리합니다.

5. 문의

개인정보 관련 문의는 GitHub 이슈로 연락해 주세요.
