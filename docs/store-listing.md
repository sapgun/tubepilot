# TubePilot Chrome 웹 스토어 등록 준비물

## 1. 짧은 설명 (132자 이내)
```
PC 유튜브 파워팩: 영상 광고 자동 스킵, SponsorBlock 구간 마킹·스킵, 영상 줌/패닝, 댓글 숨기기, 태그 기반 다시보기 라이브러리, 스크린샷·단축키
```

## 2. 상세 설명
```
🎬 TubePilot — PC 유튜브를 위한 올인원 시청 파워팩

✨ 주요 기능
• 영상 광고 자동 스킵 — 스킵 버튼 자동 클릭, 스킵 불가 광고는 음소거+고속 재생으로 빠르게 통과
• SponsorBlock 연동 — 스폰서·인트로·아웃트로·자기홍보 구간을 진행 바에 색상 마킹, 클릭 이동, 자동 스킵
• 영상 줌/패닝 — 최대 400% 확대, 드래그로 화면 이동
• 💬 댓글 숨기기 (몰입 모드) — 댓글란을 가리고 영상에만 집중
• 📌 패널 위치 자유롭게 — 우측 하단 / 플레이어 위 / 플레이어 아래(가로 툴바) + 드래그 이동
• 🌗 패널 투명도 조절
• 📚 다시보기 라이브러리 — 영상을 태그·메모와 함께 저장, 검색·필터, JSON 백업/복원
• 📷 스크린샷 — 현재 화면을 PNG로 저장 (Alt+S)
• ⌨️ 단축키 — Alt+S 캡처 · Alt+H 댓글 숨기기 · Alt+B 저장

🔒 프라이버시
• 설정과 라이브러리는 브라우저 로컬에만 저장됩니다
• 외부 전송은 SponsorBlock 구간 조회를 위한 영상 ID뿐입니다
• 개인정보처리방침: https://sapgun.github.io/tubepilot/privacy.html (Pages 게시 후 주소 확정)

※ SponsorBlock 구간 데이터는 커뮤니티 기여 기반이라 모든 영상에 있지는 않습니다.
```

## 3. 카테고리 / 언어
- 카테고리: 생산성 또는 엔터테인먼트
- 언어: 한국어

## 4. 필요 이미지
- [x] 아이콘 128px (`extension/icons/icon128.png`)
- [x] 프로모 타일 440x280 (`docs/promo-tile-440x280.png`)
- [ ] 스크린샷 1280x800 최소 1장 — 아래 가이드대로 직접 촬영

### 스크린샷 촬영 가이드 (뷰포트 1280x800)
1. 스폰서 데이터 있는 영상(예: LTT 영상)에서 진행 바 색 마커 + 떠 있는 패널
2. "플레이어 아래" 모드의 가로 툴바 바
3. 다시보기 라이브러리 (태그 칩 + 검색)
4. (선택) 댓글 숨기기 전/후 비교

## 5. 권한 정당화 (심사 응답용)
- `storage`: 설정·다시보기 라이브러리·패널 위치를 브라우저 로컬에 저장하기 위해 필요합니다.
- `https://sponsor.ajay.app/*`: SponsorBlock 커뮤니티의 스폰서 구간 데이터를 조회하기 위해 필요합니다.
- `https://www.youtube.com/*` 콘텐츠 스크립트: 광고 감지·구간 마킹·설정 패널 표시를 위해 필요합니다.

## 6. Privacy 탭 답변 (대시보드)
- 수집 데이터: 시청 중인 YouTube 영상 ID → `sponsor.ajay.app` 전송 (스폰서 구간 조회 목적)
- 그 외 개인 데이터 수집·전송 없음
- 설정/라이브러리는 `chrome.storage.local`에만 저장
- 개인정보처리방침 URL: `docs/privacy.html`을 GitHub Pages로 게시 후 입력

## 7. 등록 절차
1. [Chrome Web Store 개발자 대시보드](https://chrome.google.com/webstore/devconsole) 가입 ($5 일회성)
2. 새 항목 → `tubepilot-*.zip` 업로드
3. 스토어 등록정보 입력 (위 1~4번)
4. Privacy 탭 작성 (위 6번)
5. 제출 → 심사 대기 (며칠~몇 주)

> 참고: GitHub Pages는 공개 레포(또는 유료 플랜)에서만 동작합니다.
> 현재 레포가 비공개라면 개인정보처리방침 페이지를 별도 공개 위치에 올려야 합니다.
