기능

영상 위에 떠 있는 패널 하나로 전부 조작합니다. 패널은 드래그로 옮기거나 플레이어 아래에 가로 바로 도킹할 수 있어요.

🚫

광고 자동 스킵

재생 전 광고를 감지하면 자동으로 음소거하고 스킵합니다.

⏭️

SponsorBlock

스폰서·인트로 등 구간을 진행 바에 색으로 표시하고 자동 스킵. 마커 클릭으로 이동도 됩니다.

🔍

영상 줌

최대 400%까지 확대하고 드래그로 화면을 움직일 수 있습니다.

📷

클린 스크린샷

Alt+S 한 번이면 UI 없는 깨끗한 영상 프레임 캡처. 파일 저장·클립보드 복사 중 선택.

💬

댓글 숨기기

Alt+H로 댓글란 전체를 숨기는 몰입 모드.

🔖

다시보기 라이브러리

설명란 해시태그 자동 추출, 태그·메모 저장, 구간 북마크(시작~끝 저장, 끝에서 자동 정지). 백업·복원 지원.

⌨️

바꿀 수 있는 단축키

스크린샷·댓글 숨기기·저장 단축키를 팝업에서 직접 변경.

🎨

내 마음대로 패널

투명도 조절, 드래그 이동, 우측 하단 / 플레이어 위 / 플레이어 아래 가로 바 모드.

설치

Chrome 웹 스토어 심사 준비 중입니다. 지금은 GitHub 릴리즈에서 직접 설치하세요. (1분 컷)

  1. 릴리즈 페이지에서 최신 tubepilot-v*-extension.zip을 내려받아 압축을 풉니다.
  2. Chrome 주소창에 chrome://extensions를 입력하고 우측 상단 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드를 눌러 압축 푼 폴더 안의 extension 폴더를 선택합니다.
  4. 유튜브 영상 페이지를 열면 우측 하단에 TubePilot 패널이 나타납니다. 🎉
스토어에 정식 등록되면 이 페이지 상단의 설치 버튼이 스토어로 바로 연결됩니다. 업데이트는 릴리즈 페이지에서 같은 방식으로 덮어씌우면 됩니다.

자주 묻는 질문

무료인가요?

네, 완전 무료입니다. 자발적 후원(ETH/SOL)은 환영하지만 기능 제한은 없습니다.

제 시청 기록 같은 개인정보를 수집하나요?

아니요. 스폰서 구간 조회를 위해 시청 중인 영상의 ID만 SponsorBlock API(sponsor.ajay.app)로 전송하고, 설정·라이브러리는 브라우저 로컬(chrome.storage.local)에만 저장됩니다. 자세한 내용은 개인정보처리방침을 참고하세요.

어떤 언어를 지원하나요?

한국어, English, 日本語, Español, Português 5개 언어를 지원합니다. 브라우저 언어를 자동 감지하고, 팝업에서 직접 바꿀 수도 있습니다.

버그를 찾았거나 기능 제안이 있어요.

GitHub Issues에 남겨주세요. 버그 리포트 템플릿이 준비되어 있습니다.
