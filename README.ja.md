## 視聴を邪魔しない小さなパネル

TubePilot はデスクトップの YouTube プレーヤーに、区間表示・スキップ・ローカルライブラリを追加します。TubePilot アカウントは不要です。

## 機能

| 機能 | 内容 |
|---|---|
| 区間リピート | 保存した区間を2・3・5・10回または連続で再生し、0.5–2倍速を指定。停止・完了・動画移動で元の速度を復元します。指定区間の再生は自動区間スキップより優先されます。 |
| 続きから見る | 保存した動画の位置をローカルに記録し、再訪時に続きから見るボタンを表示。自動移動せず、未保存動画の視聴履歴は作りません。 |
| 時点メモ | 特定の時点にメモを保存し、区間・メモの一覧で検索・移動。時点メモは終了位置での一時停止を予約しません。 |
| 集中モード拡張 | コメント・おすすめ・ライブチャット・終了画面を個別に非表示。初期設定はすべてオフで選択を保存。プレーヤー操作は表示したままです。 |
| スキップを元に戻す | 6秒間表示されるボタンで元の位置に戻ります。今回の視聴では、その区間と重なる区間を自動スキップしません。 |
| 種類別の動作 | 各種類に自動・手動・表示のみを設定。全体の自動スキップ設定も適用されます。 |
| チャンネル設定 | 現在のチャンネルに全体設定・手動・表示のみを指定。表示名ではなくチャンネルリンクで区別します。 |
| 自分のスキップ区間 | 開始・終了を入力、または現在位置を記録。この動画だけに適用し、ブラウザ内に保存します。一覧から削除でき、JSON設定バックアップにも含まれます。SponsorBlockには投稿しません。 |
| 区間表示 | スポンサー、イントロ、アウトロ、自己宣伝、登録の呼びかけ、主題外の音楽をタイムラインと一覧に表示。開始・終了時刻と手動スキップを提供します。 |
| 自動スキップ | 全体および種類別に設定できます。自動スキップを無効にしても区間は表示されます。 |
| パネル | `＋ / −` で開閉、`↗ / ↙` で拡大・コンパクト表示。状態を保存し、新規インストールでは動画の下に閉じた状態で表示します。 |
| 動画広告 | 検出した広告のスキップボタン操作、シーク、速度変更を試みます。ミュートも設定可能で、終了後に元のミュート状態と速度を復元します。成功は保証されません。 |
| 視聴ツール | 最大400%ズーム、ドラッグ移動、コメント非表示。 |
| ライブラリ | タグ・メモ付き保存、検索・絞り込み、再訪時のリコール表示。 |
| 区間ブックマーク | 時間範囲とメモを保存し、移動後に区間の終わりで一時停止。 |
| スクリーンショット | 表示中のプレーヤー領域をPNGで保存・コピー。タブの画像を切り抜く方式で、動画フレームの直接抽出ではありません。 |
| バックアップ | 設定・ライブラリ・ブックマークをJSONで保存。復元時は設定とライブラリを置換し、ブックマークが含まれる場合はそれも置換します。 |

韓国語・英語・日本語・スペイン語・ポルトガル語に対応。ポップアップで言語、画像保存方法、ショートカットを変更できます。

## インストールと更新

1. [main の ZIP](https://github.com/sapgun/tubepilot/archive/refs/heads/main.zip)を展開するか、リポジトリをクローンします。
2. `chrome://extensions` または `edge://extensions` でデベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で `manifest.json` がある `extension/` を選びます。
4. YouTube を再読み込みし、動画下の `＋` でパネルを開きます。

更新前にライブラリからバックアップしてください。既存の拡張フォルダーを更新し、拡張管理画面とYouTubeを再読み込みします。重複インストールを避けてください。ポップアップの全体スイッチを変更した後もYouTubeの再読み込みが必要です。

## 操作

- 再生とスキップの設定から種類、ズーム、位置、透明度、保存などを操作できます。動画を隠さない「プレーヤーの下」を推奨します。
- コンパクト表示は340px。拡大表示は動画下の利用可能な幅、浮動パネルでは540pxで、画面幅に収まります。
- 浮動パネルは見出しをドラッグして移動、ダブルクリックで位置をリセット、クリックで開閉。全画面ではパネルを非表示にします。
- マーカーは区間の開始へ、一覧のスキップは終了へ移動します。検出されたYouTube広告中は手動スキップできません。
- `Alt+S` 撮影、`Alt+H` コメント切替、`Alt+B` 保存。ポップアップで変更可能です。

## データ・制限・プライバシー

区間は [SponsorBlock API](https://wiki.sponsor.ajay.app/w/API_Docs) のコミュニティ投稿に基づきます。未登録の広告を動画解析で発見しません。投稿がない動画と取得エラーは別の状態です。YouTube広告と動画内スポンサーは別の処理で、YouTube更新により動作が変わります。他の広告ツールとの互換性は保証されません。YouTube・ReVanced・SponsorBlockとは提携していません。

[ユーザースクリプト](https://raw.githubusercontent.com/sapgun/tubepilot/main/tubepilot.user.js) は **1.1.2**、拡張は **1.12.0** です。Tampermonkey / Violentmonkeyなどで導入できますが、新しい区間パネルやサイズ・開閉状態の保存など、拡張の全機能は含みません。Firefox/Safariの互換性は未検証です。両方を同時に実行しないでください。

設定・ライブラリ・ブックマークはブラウザー内に保存します。区間取得時に動画IDを `sponsor.ajay.app` へ送信し、通常のネットワーク情報もサービスに届きます。クラウド同期はありません。バックアップには保存動画とメモが含まれます。

権限: `storage` はローカル保存、`activeTab` はタブ撮影、`clipboardWrite` は画像コピー、`downloads` は画像保存、`https://sponsor.ajay.app/*` は区間取得に使用します。撮影には拡張アイコンをクリックするなどのユーザー操作が必要な場合があります。

## 問題解決と開発

パネルがない場合は拡張を有効にして再読み込みし、動画下や保存された位置を確認してください。マーカーがない場合は表示設定、メタデータ、取得状態を確認してください。撮影時はプレーヤーを表示し、必要に応じて拡張アイコンをクリックしてください。問題はバージョン・再現手順・動画URLを添えて[報告](https://github.com/sapgun/tubepilot/issues)してください。個人情報は含めないでください。

```sh
cd extension/test
npm install
npm test
```

テストは模擬ブラウザーで機能・ポップアップ・翻訳を確認します。実際の広告スキップを保証しません。対象ブラウザーで再生・全画面・開閉・更新を手動確認してください。[変更履歴](CHANGELOG.md) · [MITライセンス](LICENSE)
